# tools

`PresentMon-2.4.1-x64.exe` is the official Intel PresentMon command-line tool
(MIT License, https://github.com/GameTechDev/PresentMon). K2 uses it for
accurate frame-presentation timing.

Run `resolve.ps1` from the project root to download the pinned version and
verify its SHA-256. The binary is not committed to git; the license text is in
`licenses/PresentMon-MIT.txt`.
